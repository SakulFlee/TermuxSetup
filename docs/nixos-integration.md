# NixOS peer integration

The tablet setup itself is in this repository. The tablet still needs a few
entries on the NixOS peer (Dendra in the reference setup) for SSH and
Syncthing. Those entries are live host configuration and are intentionally not
generated by `setup.sh`.

Replace the placeholder values for another device.

## SSH host alias

In the workstation's Home Manager SSH configuration:

```nix
{
  programs.ssh = {
    enable = true;
    settings = {
      "tablet" = {
        HostName = "192.168.178.106";
        Port = 8022;
        User = "u0_a510";
      };
    };
  };
}
```

Add a DHCP reservation on the router for the tablet IP.

## Authorized key for the tablet

The tablet's SSH key is stored in its `~/.ssh/id_ed25519`. Add the public key
to the workstation user so the tablet can connect out (used by the OpenCode
widget):

```nix
{
  users.users.sakulflee.openssh.authorizedKeys.keys = [
    "ssh-ed25519 AAAA... u0_a510@localhost"
  ];
}
```

The reverse direction — workstation to tablet — uses the key configured as
`AUTHORIZED_KEY` in the tablet's `config.env`.

## Syncthing device and folder

On Dendra:

```nix
{
  services.syncthing.settings = {
    devices.Tablet = {
      id = "D6FXOLT-K6ANSIJ-RLFA7D7-EPI6CZO-GVVCGET-B3NMYBA-ZJ34RF6-VXO3BQ5";
    };

    folders."/mnt/ssd/Personal/" = {
      id = "personal";
      devices = [
        "HomeLab"
        "Tablet"
        "Phone"
      ];
    };
  };
}
```

The tablet's ID is generated on first Syncthing start; use the value from the
tablet, not the reference value above. Keep the folder ID (`personal`) in sync
with `SYNCTHING_FOLDER_ID` in `config.env`.

The reference tablet folder is **receive-only**:

- peer → tablet: enabled
- tablet → peer: disabled for now

Change the folder type to `sendreceive` on both sides if tablet uploads are
wanted.

## Verification

```bash
# Workstation → tablet
ssh tablet 'whoami; hostname'

# Tablet → workstation (the OpenCode widget uses this)
ssh sakulflee@192.168.178.109 'hostname'
```

The Syncthing GUI is bound to `127.0.0.1:8384` on the tablet. Tunnel it from
the workstation:

```bash
ssh -L 8384:127.0.0.1:8384 tablet
```
